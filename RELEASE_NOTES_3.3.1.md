# MeiGen MCP 3.3.1 — Midjourney naming correction

The `enhance_prompt` tool now describes Midjourney V8.2 instead of V8.1. Runtime version and installation pins are updated to 3.3.1.

The stable API model ID remains `midjourney-v8.1`; generation parameters, pricing and reference handling are unchanged. The existing Midjourney advanced options require 3.3.0 or later.

Install with `npx -y meigen@3.3.1`, preserving existing private configuration, then restart/reconnect. Confirm registry availability before changing an installation pin. Hosted MCP, ChatGPT and independent plugin/Skill publications remain separate.
